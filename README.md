#🏊 Tri and Succeed Sports 🚴 🏃

Swim. Bike. Run. Code.

🏁 What It Is

A four-page website for Tri and Succeed Sports, a fictional triathlon training center in Austin, Texas. It is built with only HTML and CSS.

🎯 Why It Exists

This project was built to practice the fundamentals of web design: structuring pages with semantic HTML, building a multi-column layout, and styling a whole site consistently from shared stylesheets.

For visitors, the site introduces TSS to prospective athletes: who the coaches are, what classes are offered, when they meet, and what each week of training covers.

🗺️ What's Inside
🏠 Home: About TSS, the coaching philosophy, athlete comments, and training links
🏃 Running: Guided Running and Racing, an 8-week course
🚴 Cycling: Improving your Cycling, an 8-week indoor course
🏊 Swimming: Swim for Fitness, a 6-week course
💪 How It's Built
🧱 Semantic HTML5 for page structure
📐 Three-column layout with CSS floats
🔤 Custom Quicksand web font
🏅 Sport icons as list bullets
🎨 Warm orange and ivory color palette
